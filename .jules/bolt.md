## 2026-09-07 - Commission Model Mapping and Query Optimization in AgentCommissionService
**Learning:** `AgentCommissionService` had a performance bottleneck in `getCommissionSummary` where `calculateMonthlyAverage` loaded full Eloquent collection objects into memory for average calculations and was executed twice—once directly and once inside `calculateYearlyProjection`. Additionally, `Commission` model lacks `deleted_at` in the database schema while declaring `SoftDeletes`, requiring explicit handling to prevent query execution errors.
**Action:** Replace in-memory collection calculations with SQL `avg('amount')` aggregations, pass precalculated `$monthlyAverage` to `calculateYearlyProjection` to eliminate duplicate query execution, and explicitly specify `protected $table = 'agent_commissions';` on `Commission`.
