## 2025-05-15 - [Laravel Query Builder: Stacked WHERE filters and Aggregate Optimization]
**Learning:** Sequential `where()` calls on the same Eloquent Query Builder instance are destructive as they modify the object in-place. When trying to perform multiple counts on the same base query (e.g., total vs. status-specific), these filters stack, leading to incorrect results (e.g., `WHERE status = 'sold' AND status = 'rented'`). Additionally, performing aggregate calculations (COUNT, SUM, AVG) via separate queries is inefficient.
**Action:** Use `selectRaw()` with conditional aggregation (e.g., `COUNT(CASE WHEN status = 'active' THEN 1 END)`) to consolidate multiple aggregate operations into a single database query. This both improves performance and avoids the logic bug of stacked filters on a shared Query Builder instance.
