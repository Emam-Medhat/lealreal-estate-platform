## 2026-03-01 - Company Portfolio Eager Loading and Aggregation Optimization
**Learning:** In `CompanyPortfolioService`, eager loading `['images', 'documents']` on property collections failed with a SQL exception (`no such column: documents.property_id`) and wasted memory since neither relationship was used in value calculations. Furthermore, calculating growth metrics by loading all past period property models into memory and performing in-memory sums/counts was slow and contained runtime errors (`BadMethodCallException` from calling `->get()` on Eloquent collections and undefined variable `$currentProperties`).
**Action:** Always check if eager loaded relationships are actually used in calculations. Replace in-memory model collection processing for historical aggregations with direct `selectRaw('COUNT(*) as total_count, COALESCE(SUM(price), 0) as total_price')` queries.
