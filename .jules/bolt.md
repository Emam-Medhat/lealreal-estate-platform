## 2025-07-12 - [Eloquent Query Builder Mutability & Schema Mismatch]
**Learning:** The Eloquent Query Builder is mutable; chaining `where()` on the same instance modifies it permanently for subsequent calls, which led to incorrect zero counts in the original `getPropertyStatistics` implementation. Additionally, relying on code-level enum strings (e.g., 'available') without verifying against the migration schema ('active') resulted in silent data accuracy failures.
**Action:** Use conditional aggregation (`selectRaw` with `COUNT(CASE WHEN...)`) to perform multiple counts in a single query, which both improves performance and avoids the pitfalls of query builder mutability. Always verify database column names and enum values in migrations before implementing filtering logic.
